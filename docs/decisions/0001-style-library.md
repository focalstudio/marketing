# 0001 · A reusable style library for Focal Studio

Status: accepted 2026-10-24 · Spikes (WebGL, Blender) not yet run · Nothing built yet

## Context

Videos are drawn by three separate systems that share nothing:

- **Pillow styles** (`video/styles/`, `video/kit/`): one Python module per look (paper, storybook, toon, lowpoly, pixel, ink), selected with `--style`.
- **Canvas kits** (`video/canvas/`): `ink.mjs` and `toon.mjs`, driven by `render.mjs` through headless Chrome and ffmpeg. Scenes import a kit directly; there is no style flag.
- **Planned**: a Tenniel-style "Wonderland" engraving.

Problems today:

- Colours are hard-coded per module (`video/kit/brand.py:16`, `video/styles/toon.py:15`, `video/canvas/ink.mjs:5`, `video/canvas/toon.mjs:7`). Canvas ink is `#2f2924`; Python ink is `(52,44,38)`.
- `apps/wildfocus.yml` has a `palette:` block that no code reads.
- Canvas kits have no registry, goldens or previews; `video/canvas/canvas.test.mjs` checks timing only.
- `video/fonts/` holds only Nunito.
- Nothing tells a new app, or Claude, which looks exist.

Goal: one low-maintenance library of styles, fonts and palettes that Claude can read, that this repo and future apps import, and that also serves designs and app logos.

## Decisions

1. **Own repo**: private `focalstudio/focal-styles`, with the CI, release and review set-up used by the other Focal repos. Licences: MIT for code, CC BY 4.0 for cards and previews, fonts under their own licences. This allows going public later without relicensing.
2. **Import by pinned vendor copy**: tagged releases; `scripts/sync-styles.mjs <tag>` copies one tag into `vendor/focal-styles/` (committed) and writes `STYLES_VERSION`. Consumer CI fails if the copy differs from the tag. Bumping is a one-line PR. No npm, no submodules.
3. **One style entry** is `styles/<id>/` with a stable kebab-case ID:
   - Hand-written: `style.md` (front-matter: id, name, status, engine, fonts, attribution; body: look, traits, do/don't, prompt recipe, subject slots), `tokens.json`, `kit.mjs`, `demo.mjs`.
   - Generated by CI: `previews/NNN.webp` (these are also the goldens), the README catalogue, the font and licence table.
   - Subject stays out of the style: demos use a neutral subject; app subjects live in consumer repos.
4. **Brand is separate from style**: styles are app-neutral and alias semantic roles (`{brand.accent}`, `{brand.paper}`, `{brand.ink}`). `brands/<app>.tokens.json` lives in the library and holds palette, fonts and an icon reference; the icon file stays in the app's repo. The unused `palette:` in `apps/wildfocus.yml` moves there.
5. **Tokens use the W3C Design Tokens Format Module 2025.10** (first stable version, 28 October 2025; a Community Group report, not a W3C standard). We validate with a small plain-Node checker rather than adopting Style Dictionary, which would add npm.
6. **Upkeep is one script**, `scripts/check.mjs`, run by one workflow:
   1. Render each demo in headless Chrome and diff against goldens (diff inside the page via `getImageData`; tolerance as in `video/tests/test_kit.py`).
   2. Validate tokens: `$type`/`$value`, alias resolution, hex or oklch colours.
   3. Lint: every font has a licence file and a `fonts.json` entry; every `style.md` has an ID and attribution.
   4. Regenerate the catalogue and fail on any diff.

   Goldens are re-blessed only on purpose, through a `workflow_dispatch` on Linux CI, because macOS and Linux antialiasing differ (see PARKING.md).
7. **Fonts**: `fonts/<family>/` holds the TTF and licence file; `fonts.json` records family, file, SPDX licence, source URL, version and the styles using it. **OFL-1.1 and Apache-2.0 are both allowed.**

   | Style | Fonts |
   |---|---|
   | Kawaii Chibi | Nunito |
   | Mascot Flat | Fredoka |
   | Monoline Icon | Manrope |
   | Naturalist Engraving | IM Fell English, EB Garamond |
   | Wonderland | IM Fell DW Pica |
   | Rubber-hose | Titan One or Lilita One; Luckiest Guy (Apache) |
   | Anime | Anton with M PLUS 1, or Dela Gothic One |

   Check each licence against the font file itself when vendoring.

   Provenance rule: fonts come only from `github.com/google/fonts`, with the licence file shipped next to the font. Fonts that are "free for personal use", come from download sites, or have unclear origin are banned. `fonts.json` records the google/fonts source path for each font, and the lint rejects any font without one.

   Apache-2.0 trade-offs:

   - Pros: more cartoon display faces; permissive for commercial use; rendered output carries no obligations.
   - Cons: vendoring is redistribution, so keep `LICENSE`, keep any `NOTICE`, and mark modifications (subsetting counts); the lint must handle two licence shapes; the licence was not written for fonts.
   - Net: neither licence carries real legal risk if the licence file ships. The risk is provenance, so we take fonts only from google/fonts. The lint requires `LICENSE.txt`, plus `NOTICE` if upstream ships one.
8. **Style names**: planned IDs are `naturalist-engraving`, `kawaii-chibi`, `wonderland-engraving`, `cartoon-hose`, `pixel-art`, `anime-cel`, plus `mascot-flat` and `monoline-icon` reserved for logo and icon work. The six Pillow styles get card-only entries (`engine: pillow`), with previews copied once from today's goldens.

## What canvas 2D can and cannot do

- **cartoon-hose** (rubber-hose, 1930s idiom): feasible are constant-width bezier limbs, squash and stretch, beat-synced loops, grain, flicker, gate weave and an iris mask. Not feasible: full frame-by-frame acting. Keep clear of any specific studio's characters.
- **anime-cel** (flat cel shading, hard line-weight variation, muted palette, grain, cinematic framing; general traits only, no series' characters or marks): feasible are tapered strokes as filled polygons, one hard shadow via a clip path, one accent colour, grain, letterbox, speed lines, impact frames and camera push or shake. Not feasible: character acting, turnarounds, painted backgrounds, hair or cloth simulation. Keep shots tight and silhouetted. Vignette "Last 25": rooftop silhouette, watch macro, impact frame "Start.", calm wide shot with icon.
- **pixel-art**: fully feasible.

## Rendering engine spikes (done)

All three engines rendered the same shot: an anime-cel pocket-watch close-up, 4 s at 30 fps, 1080×1920, with one hard cel shadow, a tapered ink outline, grain, a muted palette with one red accent, a 2-frame impact flash at 2.3 s, and the house rabbit in silhouette. Each lives on its own spike branch (`spike/webgl-cel` holds canvas 2D and WebGL, `spike/blender-cel` holds Blender) and touches no production files. The branches are not merged; code is salvaged only for the engine that wins.

| | canvas 2D | raw WebGL2 | Blender 5.2.3 (EEVEE + Freestyle) |
|---|---|---|---|
| Render time, 4 s | about 19 s | about 35 s | 62 s frames + 18 s encode |
| mp4 size | 20 MB | 64 MB | 118 MB (ffmpeg noise grain) |
| Deterministic, two runs | yes | yes | yes, by decoded pixels (PNG metadata differs) |
| Code | 125 lines | 216 lines | 319 lines Python + 9 shell |
| Install | none (Chrome) | none (Chrome) | 907 MB app |
| Look | flat, clean vector ink | almost identical to 2D, no visible gain | almost identical, plus a brush-style tapered line |

Caveats: the three differ slightly in the grain (Blender's is ffmpeg's, added at encode time) and in the sound (2D and WebGL carry the quiet rain bed; Blender is silent).

**Verdict**

- **canvas 2D is the default engine.** It matched the other two on this shot at the lowest cost and needs no install, which keeps CI and Claude's edits simple.
- **WebGL is dropped.** It looks the same at about twice the render time and more code.
- **Blender is kept as a fallback**, for what canvas 2D cannot do: real 3D (objects turning in depth, faceted low-poly with real light) and brush-style Freestyle ink. It is not in `ubuntu-latest`, so it would be a download of roughly 300 MB per CI run unless cached. Its renders are made locally and committed to `inbox/`.

The engine recommended for each style is in [video/STYLES.md](../../video/STYLES.md).

## Not chosen

- Remotion (npm, and paid beyond small teams), Motion Canvas (npm), Rive (hosted editor), AI video (little control or consistency).
- Manim and pycairo: extra dependencies for no gain over canvas.
